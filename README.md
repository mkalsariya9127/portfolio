# 💼 Milan Kalsariya - Developer Portfolio Website

A modern, responsive personal developer portfolio website crafted to showcase web development projects, technical skills, and educational background. Features an active contact form integrated with EmailJS for direct client communication.

---

## ✨ Features
- **Hero Section:** Engaging introduction with animated typing effect and quick navigation.
- **Featured Projects:** Interactive cards showcasing web applications with live demo links and GitHub source code.
- **Skills Matrix:** Organized breakdown of frontend technologies (HTML, CSS, JavaScript, Bootstrap, Tailwind).
- **Working Contact Form:** Integrated with **EmailJS** to receive visitor messages directly to inbox without a custom backend server.
- **Responsive Navigation:** Mobile hamburger menu and smooth scrolling between sections.

---

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Integration:** EmailJS API
- **Styling:** Custom responsive CSS & Flexbox

---

## 🚀 How to View & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/mkalsariya9127/portfolio.git
   ```
2. Open `index.html` in your browser.
